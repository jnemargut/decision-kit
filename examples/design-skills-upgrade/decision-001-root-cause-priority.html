Which root cause of "samey, not great" do we attack first?

The audit of both skills found four distinct causes of sameness. They compound, and you'll likely fix several eventually — but the first one you attack shapes the architecture of everything after it. Pick the foundation.

Research Context
  • The sameness has a name: distributional convergence. LLMs sample from the high-probability center of training data — Inter, purple-on-white gradients, three-column hero layouts — unless explicitly forced off it. Shuffle.dev, 925studios, Vandelay Design
  • Anthropic's own frontend-design skill bans defaults by name: "overused font families (Inter, Roboto, Arial, system fonts)" and "purple gradients on white backgrounds" — and guides five dimensions individually: typography, color, motion, spatial composition, backgrounds. Naming the banned defaults is the documented fix. anthropics/claude-code frontend-design SKILL.md
  • Audit finding: your tradition library converges on the banned font. Swiss Modern, Warm Minimal, Technical Documentary, and Glassmorphic all ship Inter as the body face. A user picking "different" traditions still gets the same typographic voice.
  • Audit finding: /visual-design never touches layout. The skill explicitly preserves structure ("only aesthetic properties change") — so every artifact keeps identical bones. Spatial composition is the dimension Anthropic's skill calls out hardest: "Asymmetry. Overlap. Diagonal flow. Grid-breaking elements."
  • Visual feedback loops are the quality multiplier. Practitioners report UI iteration dropping from 10+ blind rounds to 2–3 when the agent screenshots and inspects its own rendered output (Playwright MCP / "Eyes" skill pattern). Neither of your skills ever looks at what it produced. luca-becker.me, egghead.io, mcpmarket "Eyes"
  • Audit finding: recommendation bias narrows the funnel. The ★ recommendation plus affinity tables steer most runs toward the same few safe traditions per artifact type (briefs → Editorial Print, dashboards → Swiss Modern). Defaults dominate outcomes.
