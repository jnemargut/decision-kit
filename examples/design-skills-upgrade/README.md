# Example: Decision Kit redesigning its own design skills

This is the actual `.decisions/` record from running `/strategize` on the question: *"My /visual-design and /design-system skills are weak — outputs all look the same. Improve them and contribute back."*

Decision Kit used itself to plan the upgrade that ships in this repo: seven researched decisions (root cause, both skill upgrades, shared-core architecture, quality validation, contribution packaging, elevator pitch), each with four options, real web research, and a recommendation. The strategy brief that resulted drove the `shared/design-dna/` foundation, the `/visual-design` composition + ban-list upgrade, the `/design-system` amplification rules, and the critique gate.

Start with [strategy-brief.md](strategy-brief.md), or open [index.html](index.html) for the decision hub. Per [CONTRIBUTING.md](../../CONTRIBUTING.md), significant proposals should include their `.decisions/` folders — this folder is that receipt.
