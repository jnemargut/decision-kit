Decision 2 of 6 · /visual-design

How does /visual-design get distinctive?

The re-skin skill's catalog of 30 traditions is its identity — name-based picking, type-forward thumbnails, signature flourishes. The question is how far to go: clean the catalog, extend it into composition, or change the generation model itself.

Builds on Decision 1 (Option A): token diversity + banned defaults is the first attack. These options differ in how much further past tokens they reach.
Research Context
  • The characterful-font supply is deep — no two traditions need to share a face. 2026's distinctive picks: Bricolage Grotesque ("the trending typeface of 2025–26"), Space Grotesk, Plus Jakarta Sans, Fraunces (variable, "wonky" optical features), General Sans/Satoshi via Fontshare. Pairing one ubiquitous body with a distinctive display is "the secret weapon of modern product design." Typewolf, Precode, MaxiBestOf
  • Anthropic's fix is dimension guidance + named bans, not just better defaults. "Overused font families (Inter, Roboto, Arial, system fonts)" and "purple gradients on white" are banned verbatim; typography, color, motion, spatial composition, and backgrounds get individual direction. "The key is intentionality, not intensity." frontend-design SKILL.md
  • Composition can change without touching the DOM. CSS Grid `grid-template-areas` lets you art-direct entirely from the stylesheet — re-area existing semantic regions into magazine spreads, asymmetric heroes, broken grids via column spans and vertical offsets. Print-level art direction, same HTML. Smashing Magazine "Art Directing For The Web", HubSpot broken-grid guide
  • Audit: the catalog's convergence is concentrated, not uniform. Inter/Inter Tight appears in at least 5 of 30 traditions' stacks, and JetBrains Mono is the default mono nearly everywhere. The expressive traditions (Neo-Brutalist, Editorial Print) are already distinct — the "safe" half of the catalog is where sameness lives, and the affinity tables route most artifact types to exactly that half.
  • Audit: the skill already has a calibration hook. Step 3d fires web searches for current examples of the chosen tradition. It currently only nudges accent hue and font weight — it's an underused seam for injecting freshness without architectural change.
Options
A

Catalog overhaul in place

Rewrite the 30 traditions so no two share a typographic voice, draw from the characterful-font pool, add a BANNED DEFAULTS section the rewrite step must obey. Flow untouched.

1Tradition retuned
2Color → Type → Mood new tokens
3Flourish
4Rewrite style block ban-list enforced

Smallest diff, fully backward compatible, ships fastest

Pure data/prompt change — exactly what Decision 1 scoped

Bones still identical — a Zine brief and a Swiss brief share a skeleton

30 traditions is still a finite pool; heavy users will see repeats

★ Recommended
B

Overhaul + composition signatures (CSS-only)

Everything in A, plus each tradition gets a composition signature — grid-template-areas remixes, asymmetric heroes, broken-grid offsets, density profiles — applied purely in CSS. A new "Composition" step joins the flow.

1Tradition retuned
2Composition — bones remix via grid-template-areas new step
3Color → Type → Mood new tokens
4Flourish
5Rewrite style block ban-list + layout CSS

Attacks both top causes — tokens AND bones — in one coherent upgrade

CSS-only: DOM untouched, so artifact safety guarantee survives

Composition is the dimension Anthropic's skill weights hardest

~2× the effort of A; needs careful per-artifact-type testing

Some artifacts (dense tables/dashboards) can't take much remixing

C

Generative house blend

Keep the catalog as a grammar, add a "blend" path: the skill composes a never-before-seen tradition per project from primitives (font pool, palette logic, flourishes), seeded by the existing calibration web search.

1Catalog pick or "blend for me" new path
2Web calibration seeds primitives expanded
3Compose bespoke tradition new
4Standard flow on the blend

Infinite variety — cross-project uniqueness guaranteed

Reuses the calibration hook that already exists

Quality variance is real: composed aesthetics misfire without a critique loop (Decision 5 territory)

Blends are unpicked/unproven — undermines the catalog's "curated grammar" promise

D

Rebuild on the five dimensions

Replace the tradition catalog with Anthropic's dimension model: the skill derives a bespoke direction per artifact across typography, color, motion, spatial composition, backgrounds — catalog becomes optional inspiration.

1Artifact analysis → concept direction new
2Five-dimension derivation new
3User reviews direction, not catalog picks changed
4Rewrite + apply

Closest to documented best practice; highest ceiling

Throws away the kit's differentiator — pickable, previewable, named traditions

Biggest rewrite, breaks project memory (tokens.json continuity)

Decision pages get abstract — "direction" is harder to choose between than rendered traditions
